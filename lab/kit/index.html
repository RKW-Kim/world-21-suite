Use a scene in OBS

  • 0Or skip the URL math — the Director console builds any scene URL for you: pick a scene, a lane, type a title, copy the link.
  • 1Add a Browser source, 1920×1080, and paste the scene URL with ?v=a..f (or press V in the source preview).
  • 2Append &obs=1 — the page turns transparent and drops all chrome, so only the scene composites over your webcam or capture.
  • 3Control from the URL: &cd=300 countdown seconds · &t=frost|chameleon material · &title= &ep=07 text overrides · &wm=0|tl|tr|bl|br watermark · &q= the audience question on Q&A · &win=@handle on Giveaway.
  • 4Scenes respect prefers-reduced-motion — nothing loops forever except the tickers you ask for.

How this was built

  • SkillsInstalled and enforced: impeccable (craft floor), antislop + antislop-ui (the slop taxonomy), taste + taste-skill, brandkit — not mimicked, installed.
  • GatesEvery lane passed: 0 console/page errors · no overflow at 1080p/720p/4K · ?obs=1 alpha-verified · contrast ≥4.5:1 · emoji-free · reduced-motion safe.
  • JudgingA harsh VLM art-director pass scored all 60 lanes twice; layout bugs it caught were fixed and re-verified with geometry probes; genre-prejudice verdicts were overruled by probes.
  • Research30 external references + big-streamer conventions + the repo's own Tradify research fed the six lanes.
