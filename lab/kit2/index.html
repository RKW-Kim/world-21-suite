SMILE SCENE KIT — VERSION 2

The Tournament.

Thirty scenes. Six worlds. Zero shared styles — every file is its own design law, every scene in a world is a different composition. Judge them against each other and vote; winners shape the final kit.

Why a v2

The previous kit put 60 scenes on one shared CSS spine — same fonts, same skeleton, same watermark and ticker on everything, so starting soon and BRB looked identical with different text. v2 deletes the spine. Six worlds were built separately, forbidden from seeing each other. Nothing is shared except the logo, which stays verbatim everywhere.

Use in OBS

  • Every scene file is one browser source — add it at 1920×1080.
  • URL shape: /lab/kit2/<world>-<scene>.html
  • Worlds: obsidian · keynote · broadcast · highvis · zine · arcade

URL contract — every file

  • ?t=90 → 90-second countdown · ?t=2026-01-05T19:00 → absolute time
  • ?ep=7 → episode number · ?elapsed=2532 → elapsed offset
  • At zero the countdown holds 00:00 and the "we're live" reveal fades in — no dead screens
  • prefers-reduced-motion honoured everywhere; logos load verbatim from lab/assets/
