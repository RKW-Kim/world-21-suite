01

Colour

One name per role. If a scene needs a shade that isn't here, it is a scene-local token — it does not get promoted into the kit without a reason that applies everywhere.

THE ALIASES THAT HAVE TO GO

--border → --line (8 pages vs 5, same meaning — this pair is what let the border value drift silently). --font-display / --font-body / --font-mono → --fd / --fm. --ease-out → --eo. The warm yellows --yellow-hot and --ember fold into --hot.

02

Two families only. Display and body share --fd; everything small, spaced or numeric is --fm. Tracking is size-specific — never one value for the whole page.

03

Motion

Two curves, named by what they do. Nothing overshoots — the kit is critically damped throughout. Bounce is only ever justified by a gesture that carried momentum, and this kit has no gestures.

--eo · MOVE

cubic-bezier(.32,.72,0,1). Anything travelling: rises, merges, draws. Front-loaded, long tail, lands without bounce.

--eio · FADE

cubic-bezier(.4,0,.2,1). Anything appearing: opacity and colour only. Symmetric in and out.

DURATIONS IN USE

120–200ms feedback · 260–340ms a component arriving · 440–520ms a card turning · 620ms a merge · 760–900ms the mark resolving. Anything over 1s is a sequence, not a transition.

08

The rules

ONE NAME PER ROLE

If two names mean the same thing, one of them is wrong and it is not the majority's. --line beats --border because it is the older, shorter name — but the rule is the point, not the winner.

YELLOW NAMES A LIVE STATE

Not decoration. A yellow pill, led or underline means the thing it labels is happening or ready right now. If nothing is live, nothing is yellow.

NO CANVAS, NO rAF

One gated setInterval per scene, for the clock. Everything else is a CSS keyframe on the compositor. Animations must be scrubbable — that is what ?t= and --freeze are for.

RESOLVE ONCE, NEVER REVERT TO ZERO

A timer that counts past zero and keeps showing zero is correct. A producer holding a scene for forty minutes should never see it turn hostile or count into negatives.

THE BRAND TOKEN GUARD IS NOT OPTIONAL

scripts/sync-brand-tokens.py reads every scene's CSS and fails CI when two files disagree about the same token. It has caught real drift twice. Run it before every commit that touches a scene.
