How this dock works

Apply
Edits are staged in the dock, not pushed to the station on every click. Reorder, retag, park, add — then press Apply (the tick) and the station takes the new order at the next cut. The badge next to Apply says how many changes are waiting. Undo (or Ctrl+Z) steps back through them instantly, without touching the station.
Profiles
Type a name and press the save icon to store the working copy as a profile (a ready-made running order for an occasion). The folder icon loads a profile back into the working copy — it stages it, so you still press Apply to put it on air. The bin deletes a profile (two presses within 3s).
Right-click a row
Opens that row's menu: move, park, play now, tag as Video/Music, approve or discard a YouTube rename, remove. Remove and Discard need a second press within 3s. On-air rows are protected.
Drag & drop
Drag a row to reorder it, onto the queue to air it, onto a playlist to park it in there, or onto Available to park it outside any list. A line shows where it will land. Nothing is pushed to the station until Apply.
Add
Pastes become items at the END of the queue. A YouTube playlist link (one with list=) is detected automatically and imports as a parked group in the playlist's own order. Imports read titles only, nothing downloads.
Dot
● the link is there and its metadata is what it was when added. ● YouTube renamed it — the row carries a meta? badge; approve the new title or discard the row. ○ a local file, nothing to check. The label on the right says whether the file is cached locally (cuts work offline) or still live from YouTube.
Loudness
The wave button next to Shuffle is the station-wide loudness switch: on, every playback input gets compress + limit (no volume lift); off, the chain is removed. It applies to everything, not to single rows.
Keyboard
↑ / ↓ walk the rows, Enter opens the row menu, Esc closes it, Ctrl+Z undoes the last staged change, Tab moves between the toolbar and the list.
Groups
Parked playlists live below the queue, folded by default, under the tab their rows are tagged for. Click a header to fold/unfold. Header buttons: Play (queue at the cursor + cut now), shuf (randomize within the group), orig (restore the playlist's import order).
Prev / Skip
Skip ends the on-air item now and starts NEXT (~5s deck swap, debounced 4s). Prev queues the item before the on-air one.
Replay / Pause
File decks only. Replay restarts from 0:00; Pause freezes (Resume unfreezes). A live YouTube stream can't be paused.
ON-AIR VOL
The deck's dB mix, remembered across cuts and restarts. 0 dB = full. Parked decks are muted and paused automatically after every cut.
If the dock says…
PANEL UNREACHABLE: the dock lost the panel — press Retry now. DAEMON STALLED: the panel answers but the playout loop hasn't ticked in over 12s — Restart daemon (two presses). A daemon that is merely busy says so in the status line instead of alarming you.
